# 🩺 MediBot: Healthcare Chatbot using NLP

An AI-driven clinical triage assistant with user authentication, doctor administration dashboard, and PDF export capabilities.

## Features
- Structured Symptom Triage (`EMERGENCY`, `CONSULT_DOCTOR`, `SELF_CARE`)
- Actionable Emergency First-Aid Guidance
- Specialist Doctor Recommendations
- Patient & Admin/Doctor Role Access
- PDF Clinical Notes Export
